## Что работает

- Две реальные коллекции на основе предоставленных фотографий, без выдуманных цен и размеров.
- Поиск, категории, сортировка, закрепление, показ порциями по 24 карточки.
- Подробная карточка, галерея до восьми фотографий, стрелки и клавиатура.
- Серверное добавление и редактирование работ, черновики, архив, скрытие проданных.
- Загрузка JPG/PNG/WebP с уменьшением до 1600 px и сжатием WebP в браузере; максимум 20 МБ до обработки / 1.5 МБ после. Фото HEIC требуется преобразовать в JPG.
- Порядок фото, обложка, материал, размеры, необязательная цена, контакт и категории.
- Защита от перезаписи устаревшей карточки по revision.
- Выгрузка метаданных JSON. Этот файл не включает байты фото и не заменяет полный резервный архив.

## Разработка

Node.js >=22.13, pnpm. `npm run db:generate` генерирует миграции, `npm run build` собирает приложение. Скрипты Sites отвечают за публикацию. Миграции применяются при развёртывании. Секретов в исходниках нет.

Проверки: `node node_modules/typescript/bin/tsc --noEmit`, `node --experimental-strip-types --test tests/catalog.test.ts`, `node --test tests/api.test.mjs`.

## Важное ограничение хостинга

Прототип использует React/Vinext + D1 + R2, поскольку подключённая платформа приватного размещения — Sites, её runtime работает на Cloudflare. Это не выбранный российский production-хостинг и не гарантия доступности без VPN. Прототип хранит работы и фото на сервере; localStorage для каталога не используется.

См. ARCHITECTURE.md: для российских покупателей выбран статический React/Vite-каталог на Yandex Object Storage с отдельным редактором. Создание платного российского аккаунта и публичное размещение в рамках этой задачи не выполнялись.

## Переносимая витрина

`static/main.tsx` использует тот же React-интерфейс; Vite собирает его по `vite.static.config.ts`. Режим витрины читает catalog.json и не показывает редактор. `scripts/export-static.mjs` принимает через stdin origin и приватный service token, выгружает только опубликованные непроданные работы, скачивает их фото и собирает static-dist. Экспорт ничего не публикует и не меняет права доступа. Прототип сохраняет интерфейсную надпись приватности; не считать эту надпись защитой файлов при переносе — права должен обеспечивать выбранный хостинг.

## Визуальная версия 2

Сливовый, персиковый и лавандовый цвета, многослойный первый экран, асимметричная витрина и цветные обрамления фотографий. Галерея первого экрана переключает работы каждые 6.5 секунды, останавливается при наведении/фокусе и имеет кнопку паузы. Ручной выбор работы останавливает автоматическую смену. Параллакс реагирует на указатель без React-обновления на каждом движении. IntersectionObserver добавляет появление секций и карточек; без поддержки наблюдателя контент остается видимым. Настройка prefers-reduced-motion отключает движения и автоматическую смену. В подвале есть общий переключатель анимаций. Существующий редактор, данные и API сохранены.
