# Порядок украшений на ёлке

## Состояние

Миграция применена в Supabase: `20261015153431_reorder_tree_ornaments`.
В рабочей базе проверены права администратора, запрет для посетителей и обычных пользователей, перестановка, защита от устаревшего списка и повторяющихся ID. Проверка выполнялась в транзакции с откатом; контрольная сумма всех записей до и после совпала.

## План применения

1. При развёртывании нового проекта применить `supabase/migrations/0005_reorder_tree_ornaments.sql` после согласования изменения БД. В текущем проекте миграция уже применена.
2. Проверить, что анонимный посетитель и обычный пользователь не могут вызвать `reorder_tree_ornaments`.
3. Открыть «Управление украшениями» под администратором, перетащить карточку за ручку, закрыть окно и обновить страницу. Порядок списка и первых восьми доступных украшений на ёлке должен сохраниться.
4. Проверить отмену через Escape, перемещение касанием и управление с клавиатуры: Пробел, стрелки, Пробел для сохранения.

Функция обновляет только `tree_ornaments.position`, одной транзакцией. Применение самой миграции не меняет строки. Таблицы, изображения, названия, связи с работами и существующие RLS-политики сохраняются.

## Риски и защита

- При одновременном изменении списка с другого устройства функция проверяет исходные ID и позиции и отменяет устаревшее сохранение. Форма редактирования сохраняет несохранённые поля.
- На время короткой транзакции блокируются другие записи в `tree_ornaments`. Чтение каталога не блокируется.
- При ошибке интерфейс возвращает прежний порядок. Если соединение оборвалось после фиксации транзакции, обновление страницы покажет фактический сохранённый порядок.
- Если миграция отсутствует, например в новом проекте при переносе сайта, сохранение порядка выдаёт сообщение об отсутствующем обновлении БД; остальные операции с украшениями продолжают работать.

## Откат

Сначала отключить ручки перетаскивания в интерфейсе, затем выполнить:

```sql
drop function public.reorder_tree_ornaments(uuid[], uuid[], integer[]);
```

Удаление функции не удаляет украшения и не меняет текущий порядок. Чтобы вернуть прежний порядок после успешного перетаскивания, до удаления функции переставить карточки обратно. При ошибке транзакции позиции откатываются автоматически.
