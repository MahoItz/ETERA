# ETERA

Сайт-портфолио и каталог авторских изделий ручной работы: фигурок, ёлочных украшений и декора из гипса и бетона.

Здесь собраны небольшие вещи для дома и подарков. Ручная роспись, оттенки и детали придают каждой работе свой характер.

## Что можно найти на сайте

- Каталог работ с фотографиями и описаниями.
- Поиск, выбор категорий и сортировка изделий.
- Подробные карточки с галереей, материалами, размерами и стоимостью, если они указаны.
- Интерактивную ёлку, на которой можно рассмотреть украшения и открыть их карточки.
- Информацию о мастерской и ссылку для связи с мастером, когда она добавлена на сайт.

Сайт удобно просматривать с телефона, планшета и компьютера. Каталог помогает познакомиться с работами и выбрать изделие; наличие, детали исполнения и возможность заказа можно обсудить с мастером.
