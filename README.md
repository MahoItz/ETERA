# ETERA
Сайт-портфолио и каталог авторских изделий из гипса и бетона ручной работы. 

Фон шапки: положите изображение в `public/images/hero-background.webp`. Рекомендуется горизонтальная картинка шириной около 2400 пикселей. Фон заполняет шапку без искажения с обрезкой краёв; поверх него добавлено затемнение для читаемости текста. После замены изображения опубликованный сайт нужно пересобрать и обновить.

Кнопка «Войти» открывает форму входа для существующего аккаунта. Регистрация пользователей пока не добавлена. После входа администратора сайт сохраняет шапку, ёлку, оформление каталога и раздел «О мастерской». Управление появляется рядом с контентом: под ёлкой — «Добавить украшение» и «Управлять украшениями», у каталога — «Добавить работу», у фильтров — «Редактировать категории». Категории пока можно только добавлять; переименование и удаление не реализованы. В меню «Аккаунт» находятся настройки сайта, выход и переключатель кнопок редактирования для просмотра витрины без выхода из аккаунта. Каталог по умолчанию показывает опубликованные непроданные работы; черновики и архив доступны администратору через фильтры.

На главной странице работает вращающаяся ёлка. После входа нажмите «Добавить украшение» под ёлкой. В модальном окне задайте название игрушки, загрузите WebP с прозрачным фоном и выберите работу каталога, которая откроется при нажатии. Несколько игрушек могут ссылаться на одну работу: например, отдельные изображения Снегурочки и Деда Мороза открывают общую карточку набора. Через «Управлять украшениями» можно изменить или убрать игрушку, не меняя сам каталог.

Изображение загружается в Storage только после сохранения игрушки, при отмене файл остаётся локальным. Лучше обрезать пустые поля вокруг игрушки; фон удаляется заранее в графическом редакторе. На ёлке отображаются первые восемь добавленных игрушек, связанных с опубликованными непроданными работами. Пока доступных игрушек нет, закреплённые работы показываются в декоративных рамках. Вращение управляется перетаскиванием, стрелками и клавиатурой; при настройке уменьшения движения автовращение отключено.

Миграция `supabase/migrations/0004_tree_ornaments.sql` создаёт таблицу `tree_ornaments` с защитой RLS и переносит ранее добавленные игрушки из полей работы без копирования файлов. Уже применена к текущему Supabase-проекту.
